# 教学设计

**设计版本：** d1

**设计依据：** 课本、教参

**核心教学思路：**

从“分蛋糕怎样才公平”建立平均分的必要性，再用2人、4人、8人分蛋糕的情境，引出生活语言描述份额时的模糊，进而认识几分之一的读法、意义和写法。通过不同形状的图形、非平均分反例和给定分数画图，让学生在语言、符号与图形之间转换。

## 教学流程

| 环节 | 教学活动 | 设计意图 |
|---|---|---|
| 1. 导入：公平分蛋糕 | 观看乐乐和小海分蛋糕的情境，判断分法是否公平，追问“怎样分才公平”，归纳每份一样大就是平均分。 | 激活生活经验，建立平均分的必要性。 |
| 2. 探索：人数增加 | 由2人扩展到4人、8人，安排学生尝试分蛋糕、比较分法是否平均；讨论一份可以叫“半个”“小半个”“小小半个”等。 | 让学生发现日常说法不够精确，产生新的数学表达需求。 |
| 3. 归纳：认识几分之一 | 介绍二分之一、四分之一、八分之一；反复说清“把一个蛋糕平均分成几份，取其中一份”；再把这句话对应到分数线、分母和分子的位置，练习读写。 | 把平均分的操作和分数符号建立联系，而不是只记名称。 |
| 4. 应用：正例与反例 | 用不同形状的蛋糕判断涂色部分表示几分之一；对没有平均分的长方形分法进行辨析，并讨论怎样改才合理。 | 检验学生是否依据平均分及份数判断，而非依赖形状或块数。 |
| 5. 迁移与总结 | 给出六分之一，请学生自行画图表示，展示不同方案并说明理由；对有争议的“多个物体圈出一个”的方案暂留问题。 | 从识图转向主动构造，观察学生对“整体”和“其中一份”的理解。 |

## 关键教学问题

**问题1：** 为什么从中间分比较公平？“公平”在这里具体意味着什么？

**问题2：** “半个”“小半个”能不能准确区分四人分和八人分时的一份？数学上怎样说得更清楚？

**问题3：** 为什么圆形和方形的蛋糕都可能表示四分之一？判断的依据是什么？

**问题4：** 一个图形被分成五块，就一定能把其中一块称为五分之一吗？

## 预设学生困难

- 只数分成几块，却忽略各份是否同样大。需要用正反例反复追问“是不是平均分”。
- 能读出四分之一，却说不清分母4和分子1各表示什么。需要回到完整的平均分表述。
- 认为分数与图形形状或方向有关。可以对照不同形状中同样的平均分关系。
- 在自由画图中对“一个整体”的理解不一致。先请学生说明把什么看作整体，再决定是否在本课继续讨论。

## 课堂评价

- 给出平均分与非平均分的图形，请学生判断能否用指定的几分之一表示，并解释理由。
- 给出二分之一、四分之一、八分之一的图形，让学生完成读写，并用“平均分成几份，取其中一份”解释。
- 给出六分之一，让学生画出一种表示方式并说明整体、平均分的份数和所取的一份。重点评价解释是否成立，而不只看写出的分数是否正确。
