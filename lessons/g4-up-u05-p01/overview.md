# 课程概览

**课题：** 《几分之一》

**学段 / 年级：** 小学 / 四年级

**教材位置：** 上学期 / 分数的初步认识

**课型：** 概念形成课

**建议课时：** 待核实

## 教学目标

理解几分之一来自把一个整体平均分；能在图、自然语言与分数符号之间双向转换，并辨别没有平均分的反例。

## 教学重点

理解把一个整体平均分成若干份，其中一份可以用几分之一表示。

## 教学难点

将平均分的图形、自然语言与分数符号相互转换，辨别没有平均分的反例。

## 我的教学思考

学生会说“半个、小半个”，但这些日常词并不足以精确说明整体被怎样分、取了多少。怎样让分数成为一种有必要出现的新语言？
