# 教学设计

**设计版本：** d1

**设计依据：** 教材、教师教学用书及参考教案（待补充）

**核心教学思路：**

从学生熟悉的购物经验出发，认识单价、数量和总价；通过具体计算归纳数量关系，再利用乘除法关系解决逆向问题，最后迁移到预算采购活动。

## 教学流程

| 环节 | 教学活动 | 设计意图 |
|---|---|---|
| 1. 情境导入 | 乐乐为春游采购，观看购物视频并提取数学信息 | 激活购物经验 |
| 2. 概念认识 | 区分“5块饼干”和“每块3元”，认识数量与单价 | 理解三个量的实际含义 |
| 3. 关系建立 | 计算饼干总价，讨论可乐缺少单价的问题，归纳基本关系 | 从具体算式抽象一般关系 |
| 4. 逆向求解 | 根据薯片总价与数量求单价，根据雪碧总价与单价求数量 | 理解乘除法之间的联系 |
| 5. 综合应用 | 40元预算采购，记录并计算购物方案 | 迁移应用数量关系 |
| 6. 课堂总结 | 回顾三个量的意义和关系 | 整理知识结构 |

## 关键教学问题

**问题1：** “5块饼干”和“每块3元”有什么不同？

**问题2：** 只知道买了6瓶可乐，能不能算出总价？为什么？

**问题3：** 21元买了3袋薯片，为什么用21÷3求单价？

**问题4：** 这些购物算式有什么共同点？能否用单价、数量、总价表示？

## 预设学生困难

- 混淆不同商品的单价。
- 只记住公式，不能解释算式的实际意义。
- 求单价时忽略“元/袋”等单位。
- 在预算活动中遗漏部分商品的费用。

## 课堂评价

- 能否正确识别单价、数量、总价？
- 能否解释为什么使用乘法或除法？
- 能否独立完成一道逆向求解题？
- 能否正确记录并计算购物方案？
