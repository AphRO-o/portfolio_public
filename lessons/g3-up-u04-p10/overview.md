# 课程概览

**课题：** 《单价、数量、总价》

**学段 / 年级：** 小学 / 三年级

**教材位置：** 上学期 / 用一位数除

**课型：** 数量关系与应用课

**建议课时：** 待核实

### 1. 教学目标

1. 知道“单价、数量、总价”的实际含义；
2. 掌握“单价×数量=总价”，并推出求单价与数量的另两个数量关系式；
3. 理解数量之间的相互关系，并运用这组关系式解决简单的生活问题。

### 2. 教学重点

掌握“单价×数量=总价”，并运用该式解决实际问题。

### 3. 教学难点

理解单价、数量、总价这三个量之间的相互关系。

### 4. 我的教学思考

本课的重点不是教学生计算购物金额，而是帮助他们将已有的购物经验抽象为一般的数学关系。

我特别关注“每”在单价概念中的作用，希望学生理解“每件商品的价格”，而不只是机械识别关键词或记忆公式。

本课尝试通过春游采购这一连续情境，让学生经历认识三个量、建立数量关系、逆向求解和实际应用的过程。
