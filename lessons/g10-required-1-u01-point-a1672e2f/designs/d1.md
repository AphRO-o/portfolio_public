# 教学设计

**设计版本：** d1

**设计依据：** 本次《集合》无生模拟试讲转录与板书照片。以下记录实际采用的教学路线；数学表述上的问题留在复盘中辨析，不视为推荐讲法。

**核心教学思路：**

从五班学生、身高大于1.7米的同学、直线 $l$ 上的点和方程 $x^2+1=0$ 的解出发，寻找“按条件讨论一些对象”的共同特征，引入集合与元素；借助图示和符号建立元素与集合的关系，再通过对比与反例认识集合的性质，最后介绍集合的类型及常用数集。

## 教学流程

| 环节 | 教学活动 | 设计意图 |
|---|---|---|
| 1. 导入 | 以高中第一节数学课“认识大家”为情境，呈现五班学生、身高大于1.7米的同学、直线 $l$ 上的点、方程 $x^2+1=0$ 的解，追问共同点，引入“集合”。 | 从生活对象过渡到几何、代数对象，感受集合语言的适用范围。 |
| 2. 表示 | 画圈示意集合 $A$ 与元素，说明大写字母表示集合、小写字母表示元素；板书 $a\in A$、$2\notin A$，用大括号列出元素。 | 建立图示、文字和数学符号的联系。 |
| 3. 性质 | 比较 $\{1,3,5,7,9\}$ 与改变顺序后的写法，引出无序性；比较“身高大于1.7米”与“身高很高”，引出确定性；以重复写出1的例子引出互异性。进一步追问“老师不知道谁超过1.7米，还能构成集合吗？” | 通过对比与讨论理解集合元素的特征，特别是确定性。 |
| 4. 分类与数集 | 结合导入例子介绍有限集、无限集；由 $x^2+1=0$ 在实数范围内无解引出空集；介绍 $\mathbb N$、$\mathbb Z$、$\mathbb Q$、$\mathbb R$ 及属于关系的简单判断。 | 扩展集合的例子，熟悉常用数学语言。 |
| 5. 总结 | 回顾集合、元素、属于与不属于、三种性质、集合类型及常用数集。 | 梳理本课涉及的术语和符号。 |

## 关键教学问题

**问题1：** “五班的学生”“身高大于1.7米的同学”“直线 $l$ 上的点”“方程的解”，这些说法有什么共同点？

**问题2：** 如果老师不知道哪些同学身高超过1.7米，他们还能构成一个集合吗？“身高很高”为什么不同？

**问题3：** 改变大括号中元素的顺序，集合是否改变？一个元素写了两次，是否就有了两个这样的元素？

## 预设学生困难

- 可能把“老师不知道具体有哪些元素”误认为集合不确定，需要区分条件是否明确与是否已经掌握元素名单。
- 可能将空集理解为“有一个不存在的元素”，需要明确空集没有任何元素；方程解集为空必须说明讨论的是实数范围。
- 可能把集合的三种性质理解成书写禁令，而没有理解元素本身的特征。

## 课堂评价

- 判断“本班身高大于1.7米的同学”和“本班身高很高的同学”能否按给定条件确定成员，并说明理由。
- 判断 $\{1,2,1\}$ 与 $\{1,2\}$ 是否表示同一个集合，以及 $-\sqrt2\in\mathbb R$ 是否成立。
- 说明 $x^2+1=0$ 在实数范围内的解集为什么是空集，并判断空集属于有限集还是无限集。
