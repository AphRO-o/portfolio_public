# 教学设计

**设计版本：** d1

**设计依据：** 2026沪教五上P29，教案。

**核心教学思路：**

通过三位教师的飞镖成绩，让学生经历“比较单轮成绩—比较总分—发现次数不同—寻找可比标准—计算平均每次得分—估计与验证”的过程，初步建立平均数的意义，并尝试迁移到小组数据与生活情境。

## 教学流程

| 环节 | 教学活动 | 设计意图 |
|---|---|---|
| 1. 情境导入 | 播放数学老师和语文老师飞镖比赛的视频，先比较单轮成绩，再观察完整比赛。 | 让学生发现不同轮次胜负可能不同，提出“总体谁更擅长”的问题。 |
| 2. 比较总分 | 汇总语文老师6次共42分、数学老师5次共40分。先尝试总分比较，再指出次数不同；讨论删去语文老师最后一次成绩的办法及其问题。 | 发现总分不能直接比较次数不同的成绩，形成寻找新标准的需要。 |
| 3. 引入平均数 | 提出把总分平均分配到每一次：42÷6＝7（分），40÷5＝8（分）。解释7和8是平均每次的得分，引出“平均数＝总数÷数据的个数”。 | 由具体问题建立平均数的计算方法与初步意义。 |
| 4. 估计与验证 | 出示英语老师4次投掷成绩，先不计算，估计平均分；根据最高6分、最低2分判断范围，再计算15÷4＝3.75（分）。 | 让学生先作有依据的估计，再用计算检验，认识平均数的取值范围。 |
| 5. 小组应用 | 让各组计算本组英语考试成绩的平均分，并比较各组结果。 | 尝试把平均数应用到新的数据情境。（真实课堂实施前需调整数据隐私与比较方式。） |
| 6. 课末思考 | 提出“身高1.3米，平均水深1.2米，是否安全”的问题，留待后续讨论。 | 引出平均数不能代表每个具体位置的数值。（真实教学应当场明确：不能据此判断下水安全。） |

## 关键教学问题

**问题1：** 语文老师总分42分，数学老师总分40分，但两人投掷次数不同，只比较总分公平吗？为什么？

**问题2：** 如果删去语文老师的一次成绩再比较，是否合理？有没有既保留全部成绩、又考虑次数差异的方法？

**问题3：** 42÷6和40÷5中的6、5分别表示什么？7分和8分表示什么？

**问题4：** 英语老师每次成绩最低2分、最高6分，平均分可能是7分吗？为什么？

## 预设学生困难

- 只比较总分而忽略次数不同；可回到两人投掷次数，追问比较的标准是否一致。
- 提出删除一次成绩；需要讨论删去哪一次以及为何不能任意舍弃已发生的成绩。
- 把平均数理解为每次实际得分，或理解为成绩“稳定在某个数附近”；应回到平均分配的含义。
- 认为平均数必须等于数据中某一个实际值；可借助3.75分的结果进一步辨析。

## 课堂评价

- 给出两组投掷次数不同的成绩，要求列式比较平均每次得分，并解释除数的含义。
- 不计算具体平均数，先根据一组数据的最大值和最小值判断某个估计是否可能。
- 解释“平均每次8分”是否意味着每次都投中8分，以及平均水深能否保证某处水深安全。

**后续修改提示：** “移多补少”、虚构或匿名小组数据、平均数不一定实际出现等属于试讲后的改进方向，并非本版已经实施的活动。
