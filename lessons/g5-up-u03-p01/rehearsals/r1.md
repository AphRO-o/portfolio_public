# 试讲复盘

**试讲版本：** r1
**日期：** 2026-10-17
**试讲形式：** 无生试讲
**试讲时长：** 11分钟
**采用的教学设计版本：** d1

## 本次试讲概况

我用了数学老师和语文老师比赛飞镖的视频：先看每轮谁分高，再算总分，最后发现两个人投的次数不一样。语文老师6次42分，我5次40分，直接比总分不够合理；如果把语文老师最后一次去掉，又是在随意丢掉一部分成绩。这样就引出了比较“平均每次得分”的需要。后面还用了英语老师的成绩来估计平均数的范围，安排了小组计算和平均水深的课末问题。

## 本次试讲中值得保留的设计

### 1. 飞镖比赛制造了需要平均数的问题

总分42比40高，但6次和5次不能直接放在一起比；学生预设提出“去掉最后一次”，也能顺势讨论这种处理为什么不合理。我想保留这个主线。下一次可以把理由讲得更准确一些。

### 2. 英语老师的例题先估计再计算

英语老师最高6分、最低2分。我先让大家猜平均分，再问为什么不可能到7、8分，最后算出15÷4＝3.75分。这比一上来就列式多了一步思考，也能让学生检查答案是否合理。这里还有一个可以顺手追问的问题：英语老师真的投出过3.75分吗？平均数不一定是实际出现过的数。

## 发现的主要问题

### 1. 引出了平均数的需要，却没有充分解释平均数本身

从“把总分平均分到每一次”很快跳到了42÷6和40÷5。学生可能学会了算，但还没真正理解为什么这样算。我说“成绩稳定在8分上下、7分上下”也不准确。平均数表示一种平均水平，不等于成绩稳定；两组数据平均数相同，波动也可能完全不同。

**改进方向：** 保留原情境，在列除法之前考虑增加一个很短的“移多补少”示意，让学生看见把总分重新平均分配的过程。解释8分时就说：如果把五次投掷的总分平均分给每一次，每次相当于8分；不是每次真的投了8分。

### 2. 课堂提问还有不少替学生回答的地方

有些地方我刚问完就用“是不是”把结论带出来了，学生真正需要解释的机会不够。特别是平均数的含义、除数为什么不同，本来都可以让学生说清楚。

**改进方向：** 少问“是不是更厉害”，多问“你为什么觉得这样比较合理”“这个8表示什么”“如果每次得分差别很大，平均数还会是8吗”。留出一点思考时间，不急着把话接完。

### 3. 小组活动的材料与评价目标需要调整

让大家公开计算本组英语考试平均分、再比哪组最高，虽然能练习计算，但会牵涉个人成绩信息，也容易把注意力带到小组排名上。真实课堂不适合直接照搬。

**改进方向：** 换成虚构或匿名数据，最好让不同小组的数据个数不同，要求解释为什么要比平均数而不是总分。评价重点放在计算和解释，不是给学生排名。

### 4. 平均水深的悬念不能留下安全误解

最后的问题很适合说明平均数不能代表每个具体位置的水深。但如果直接留到下节课，学生可能误以为“平均水深比身高低”意味着可以下水。

**改进方向：** 当堂明确：仅凭平均水深不能判断安全，不能因此进入不熟悉的水域。至于为什么有些位置可能远深于平均水深，可以留作数学上的后续讨论。

## 板书复盘

板书至少需要清楚对应三位教师的投掷次数、总分、平均数计算与结论。尤其语文老师6次、数学老师5次，最好用表格标明次数，不能让空格看起来像0分。

## 对本次教学设计的进一步认识

### 1. 让学生觉得“需要它”，还不等于理解“它是什么”

这次我比较顺利地把学生带到了平均数的计算，但真正需要补的是概念解释。飞镖比赛回答了为什么要用平均数，接下来还要回答平均数究竟表示什么、有什么局限。英语老师的3.75分和平均水深问题，其实都能服务于这一点，不一定要继续增加计算题。

### 2. 平均数的范围要说得准确

平均数应在一组非空数值数据的最小值与最大值之间，**可以等于端点**。如果每次都投6分，平均数就是6分。英语老师的例题可以顺便让学生辨析这一点。

## 下一版本修改计划

1. **修正概念语言：** 删除“稳定在平均数上下”的说法，明确平均分配与平均水平的含义。
2. **补一个直观环节：** 结合教材判断是否加入简短的移多补少示意，再进入除法计算。
3. **调整应用任务：** 用虚构或匿名数据替代真实英语考试成绩，明确评价学生的解释而不是排名。
4. **处理安全边界：** 平均水深问题保留，但下课前必须明确不能据此判断下水安全。

## 阶段性总结

这节课的主线我想保留：总分比较遇到困难，才需要平均数。相比单纯讲公式，这样更有问题意识。但现在概念形成仍有一段没有讲透：为什么总数除以个数，得到的数又能代表什么。下一版不用推翻情境，先把这一步补扎实，再处理练习和课堂语言。
