# 教学设计

**设计版本：** d1

**设计依据：** 已有的20以内加法经验、10加几的认识，以及两次《9加几》无生模拟试讲转录。

**核心教学思路：**

从足球收纳情境提出9+3，先接纳接着数、摆小棒数等已有策略，再借助10+2和“十几就是十和几”，提出能否不逐个数数的问题。通过移动小棒，把3分成1和2，先使9与1凑成10，再计算10+2。随后将方法用于其他9加几算式，促使学生从操作走向数的分解与计算。

## 教学流程

| 环节 | 教学活动 | 设计意图 |
|---|---|---|
| 1. 情境导入 | 播放乐乐收拾足球的情境：原有9个足球，又拿来3个，提出“一共有多少个足球”，列出9+3。 | 从具体问题引出9加几。 |
| 2. 回顾已有方法 | 邀请学生说出12的求法：从9接着数3个，或摆出9根与3根小棒再数出总数。 | 承认已有算法有效，并为比较方法作准备。 |
| 3. 寻找更方便的算法 | 写出10+2，回顾“十几就是十和几”，比较9+3与10+2的结果，提出能否把9+3转化为熟悉的10+2。 | 利用已学知识产生方法转化的需求。 |
| 4. 操作与归纳 | 用小棒表示9和3；从3根中移出1根给9根，凑成10根一捆，剩下2根。用语言说明“把3分成1和2，9和1凑成10，10加2等于12”，引出“凑十法”。 | 建立实物操作与数的分解、算式转化之间的联系。 |
| 5. 练习与总结 | 带领计算另一道9加几（第一次使用9+5，第二次使用9+8）；再安排独立练习或板演。追问“为什么要分出1”。 | 从共同操作逐渐转向独立应用，检验对凑十理由的理解。 |

## 关键教学问题

**问题1：** 9+3可以一个一个数出来。我们已经会算10+2，能不能借助它来算9+3？

**问题2：** 为什么要把3分成1和2？移动小棒之后，数量有没有改变？

**问题3：** 计算另一道9加几时，9还差几凑成10？另一个加数应怎样分？

## 预设学生困难

- 学生可能只会接着数，暂时想不到转化为10加几。可用9根和3根小棒帮助观察“9还差1”。
- 学生可能知道要“借1”，却说不清另一个加数如何分解。需要让学生同时指出移走的1根与剩余的小棒，并用数学语言复述。
- 学生可能认为摆小棒的方法不符合练习要求。应区分“摆小棒是正确的理解工具”和“这一轮练习希望尝试用凑十法表示计算过程”。

## 课堂评价

- 给出一道新的9加几算式，观察学生能否正确分解另一个加数，并写出凑十后的计算过程。
- 请学生解释“为什么分出1”，判断其是否理解9与1凑成10，而非仅记住固定步骤。
- 对比接着数与凑十法，让学生说明两种方法都能求得结果，以及本课所学方法的便利之处。
