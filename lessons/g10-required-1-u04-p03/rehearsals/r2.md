## 一、本次试讲概况

与第一次边备边讲相比，第二次试讲明显更加顺畅。

经过重新理解单调性定义并规划板书，讲解过程中不再需要频繁确认下一步数学推理是否成立，能够将更多注意力投入课堂语言和概念解释。

本次采用了较自然的脱稿表达，并尝试通过熟悉函数的图像、一次函数的代数证明及二次函数的反例解释单调性的数学意义。

但从转录来看，课堂仍存在教师引导性提问过多、部分结论由教师直接给出、概念生成顺序不够理想等问题。

### 本版主要修改

相较 r1，本版重点调整了：

- 预先规划黑板空间，区分函数图像、代数证明与正式定义。
- 减少长时间面对黑板讲话。
- 加强对区间 I 的解释，利用二次函数说明单调性与研究区间的关系。
- 在代数证明前，先明确需要比较 f(x₁) 与 f(x₂) 的大小。
- 尝试将抽象定义与具体函数图像联系起来。

### 实际教学过程

根据试讲转录，本次实际课堂大致按以下顺序展开。

| 环节 | 实际教学内容 | 观察 |
|---|---|---|
| 1. 复习导入 | 回顾指数函数、对数函数及其图像 | 利用已有知识引出上升趋势 |
| 2. 直观观察 | 观察一次函数图像，选取 x₁ < x₂ | 建立自变量与函数值的比较 |
| 3. 讨论任意性 | 移动图像上的点，讨论取值条件 | 尝试说明不能只依赖固定点 |
| 4. 代数证明 | 利用作差法证明 f(x)=2x+1 递增 | 从图像判断进入代数推理 |
| 5. 形成定义 | 给出增函数、减函数的正式定义 | 将前面的比较关系一般化 |
| 6. 解释区间 | 利用二次函数说明区间 I 的必要性 | 回答第一次试讲留下的问题 |
| 7. 课堂练习 | 布置指数函数、对数函数单调性证明 | 尝试迁移证明方法 |

值得注意的是，本次实际顺序与整理后的 d1 不完全一致：正式定义与区间讨论发生在一次函数证明之后。

## 二、本次试讲中值得保留的设计

### 1. 利用具体函数建立符号表达

通过 f(x)=2x+1 的图像，先比较两个自变量，再比较对应的函数值。

这一过程使“图像上升”与：

x₁ < x₂ ⇒ f(x₁) < f(x₂)

建立了联系。

相比直接给出定义，这种处理更有利于学生理解符号关系的直观来源。

### 2. 在作差前明确证明目标

试讲中先提出：

“我们的目标是什么？”

再引导学生将比较函数值大小转化为判断差的符号。

这一顺序具有明确的数学逻辑：

比较函数值 → 构造差式 → 判断正负 → 得到大小关系。

作差不再只是突然出现的计算技巧，而是为完成证明目标服务。

### 3. 利用二次函数解释区间 I

通过观察二次函数在不同区间上的变化趋势，解释为什么不能只根据整个定义域给函数贴上“递增”或“递减”的标签。

这是对第一次试讲中自身困惑的直接回应。

本次最重要的概念改进，是开始将定义中的区间条件作为需要理解的数学内容，而不是仅仅作为符号约定。

## 三、发现的主要问题

### 1. 学生独立思考的空间不足

转录中多次出现：

- “对不对？”
- “是不是？”
- “大家肯定还记得……”
- “这是不是特别简单？”

教师经常在提出问题后迅速给出答案或继续解释。

例如，在比较函数值大小和总结增减函数定义时，学生主要是在确认教师的推理方向。

影响：

模拟课堂虽然能够顺畅推进，但较难判断学生是否真正理解每一步的数学意义。

下一版可以减少确认性提问，增加要求学生解释理由的问题。

### 2. 对‘任意’的解释还不充分

试讲通过移动图像上的两个点，说明比较关系不依赖于某一对固定点。

这一思路基本正确，但需要进一步明确：

找到若干对满足条件的点，仍然不能证明整个区间上的单调性。

严格定义要求对区间内任意两个满足 x₁ < x₂ 的自变量，函数值关系都成立。

因此，图像演示主要用于形成直观认识，不能代替全称条件的证明。

### 3. 定义、证明与区间条件的顺序仍可优化

本次实际先证明一次函数递增，再给出正式定义，最后通过二次函数解释区间 I。

这一顺序能够完成教学，但也存在问题：

学生在尚未完整建立定义时，就已经使用接近正式定义的证明步骤。

此外，区间 I 的必要性直到定义呈现后才得到充分说明。

下一版可以考虑先利用二次函数明确研究范围，再形成完整定义，最后进行严格证明。

这属于教学结构优化，并不意味着本次证明本身不成立。

### 4. 复习导入存在不必要的负面评价

转录中出现类似：

“这不是上次才学的吗？”

“不要老是提醒啊。”

这些语言在模拟课堂中可能是为了营造真实感，但真实课堂中容易让暂时遗忘知识的学生感到压力。

建议用简短的图像提示或复习问题替代责备性表达。

### 5. 课末练习的难度跨度较大

本课主要示范了 f(x)=2x+1 的单调性证明，课末却直接要求证明指数函数和对数函数的单调性。

这些函数的严格证明可能需要额外的知识基础，不能简单照搬一次函数的作差过程。

如果目标是巩固定义证明法，可以先安排更接近示例的代数函数，再逐步拓展到其他函数。

## 四、板书复盘

本次板书开始形成明确分区：

**左侧：函数图像经验**

- 已学函数
- 图像的上升与下降趋势

**中间：具体函数及证明**

- f(x)=2x+1
- x₁ < x₂
- 函数值比较
- 作差推理

**右侧：正式定义与区间条件**

- 区间 I
- 任意两个自变量
- 增函数、减函数
- 二次函数示例

相较第一次，板书不再只是记录讲过的内容，而开始承担组织课堂数学逻辑的作用。

但仍然存在：

- 后半段字号逐渐变大。
- 板书空间预算不足。
- 数学符号较密集。
- 临时过程与最终结论没有完全区分。
- 部分内容可能需要及时擦除。

## 五、下一版本修改计划

## 六、阶段性总结

第二次试讲明显比第一次顺畅，说明第一次感受到的压力并不完全来自高中数学教学本身，也与我对这一知识点尚不熟悉有关。

当数学逻辑更加明确后，讲解过程的认知负担有所下降，能够更加自然地组织语言并关注教学流程。

目前的主观体验仍然存在差异：

小学数学试讲更像一种探索性游戏，容易产生好奇和情绪奖励。

高中数学试讲更像严谨的知识工作，需要关注概念的准确性、证明的完整性以及符号表达。

两种试讲都能进入较为专注的状态，但仅凭目前的模拟经验，还不能判断哪一个学段更适合长期任教。

本次最大的收获是：

**数学定义中的每一个限定条件，都应当有可以向学生解释的理由；而教师自己理解这些理由，是开展概念教学的前提。**
