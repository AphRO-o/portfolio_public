# 教学设计

**设计版本：** d1

**课题：** 函数的单调性

**设计依据：** 已有函数知识、单调性定义及试讲研究；教材与教师教学用书待核实

**设计状态：** 初版设计，经历两次模拟试讲

**核心教学思路：**

从熟悉函数的图像出发，将“从左往右上升或下降”的直观观察翻译成自变量与函数值的大小关系，再通过对任意性和区间条件的讨论，形成单调性的正式定义，最后尝试利用定义进行代数证明。

**核心路径：**

图像直观 → 两个自变量的比较 → 任意性 → 区间条件 → 正式定义 → 作差证明

*说明：这是整理后的教学设计路径。第二次实际试讲中，先进行了简单一次函数的作差证明，再给出正式定义并讨论区间 I。*

## 教学流程

| 环节 | 教学活动 | 设计意图 |
|---|---|---|
| 1. 观察函数 | 回顾指数、对数及一次函数图像 | 激活已有函数经验 |
| 2. 数学表达 | 在图像上取 x₁ < x₂，比较函数值 | 从直观走向符号 |
| 3. 讨论任意性 | 思考一对点能否代表整个区间 | 理解全称条件 |
| 4. 讨论区间 | 利用二次函数的不同变化趋势 | 理解区间限定 |
| 5. 形成定义 | 整合区间、任意性和大小关系 | 建立规范概念 |
| 6. 代数证明 | 证明 f(x)=2x+1 的单调性 | 从观察走向证明 |
| 7. 迁移总结 | 回顾二次函数并整理定义结构 | 巩固概念边界 |

## 关键教学问题

**问题1：** 怎样准确描述图像的上升趋势？

观察函数 f(x)=2x+1，在图像上选择两个横坐标：

x₁ < x₂

发现对应的函数值满足：

f(x₁) < f(x₂)

将“从左往右上升”转化为两个函数值之间的大小关系。

**问题2：** 只找到一对满足条件的点，够不够？

如果仅存在一对 x₁ < x₂，使得 f(x₁) < f(x₂)，不能说明函数在整个研究区间上单调递增。

需要对区间内任意两个满足 x₁ < x₂ 的自变量进行比较。

由此引入“任意”的要求。

**问题3：** 为什么需要区间 I？

观察二次函数 f(x)=x²。

其定义域为 R，但在不同区间具有不同的变化趋势：

- 在 (-∞,0] 上单调递减。
- 在 [0,+∞) 上单调递增。

因此不能直接断言它在整个定义域上单调递增或单调递减。

单调性必须结合具体研究区间描述。

**问题4：** 怎样从图像观察走向代数证明？

以 f(x)=2x+1 为例。

任取 x₁,x₂∈R，且 x₁ < x₂。

为了证明：

f(x₁) < f(x₂)

考虑作差：

f(x₁)-f(x₂)

= (2x₁+1)-(2x₂+1)

= 2(x₁-x₂)

因为 x₁ < x₂，所以：

2(x₁-x₂) < 0

从而：

f(x₁) < f(x₂)

因此 f(x)=2x+1 在 R 上单调递增。

## 正式定义

设函数 f(x) 的定义域为 D，区间 I⊆D。

如果对于区间 I 内任意两个自变量 x₁、x₂，当 x₁ < x₂ 时，都有：

f(x₁) < f(x₂)

则称函数 f(x) 在区间 I 上单调递增。

如果对于区间 I 内任意两个自变量 x₁、x₂，当 x₁ < x₂ 时，都有：

f(x₁) > f(x₂)

则称函数 f(x) 在区间 I 上单调递减。

**定义中各条件的作用：**

- 区间 I：明确讨论单调性的范围。
- 任意：排除只凭个别点判断的情况。
- x₁ < x₂：规定自变量的比较顺序。
- f(x₁) 与 f(x₂)：刻画对应函数值的变化。

## 预设学生困难

**困难一：将“存在”误认为“任意”**

学生可能认为，只要找到两个满足函数值大小关系的点，就能证明单调性。

应通过反例说明：个别点满足条件不等于整个区间满足条件。

**困难二：忽略区间条件**

学生可能将函数简单分成“增函数”和“减函数”，忽略同一函数在不同区间上的变化差异。

通过二次函数帮助学生认识研究区间的必要性。

**困难三：不知道为什么使用作差法**

学生可能记住证明步骤，却不理解作差的目的。

应先明确证明目标是比较 f(x₁)、f(x₂) 的大小，再引出作差。

## 板书设计

**左侧：已有函数经验**

- 指数函数、对数函数图像
- 上升、下降的直观观察

**中间：具体函数与证明**

- f(x)=2x+1 的图像
- x₁ < x₂
- 函数值大小关系
- 作差证明过程

**右侧：正式定义与概念边界**

- 区间 I
- 任意 x₁、x₂
- 单调递增与单调递减
- 二次函数的区间示例

板书应区分临时推导与需要保留的核心结论，避免在证明过程中耗尽空间。

## 课堂评价

- 能否将图像上升、下降转化为函数值的大小关系？
- 能否说明为什么不能只取一对点？
- 能否结合二次函数解释区间 I 的必要性？
- 能否独立完成简单一次函数的单调性证明？

## 课后练习

1. 根据定义证明指数函数 y=aˣ 在 a>1 时的单调性。
2. 根据定义证明对数函数 y=logₐx 在 a>1 时的单调性。

*练习适切性需结合学生已学知识确认。第二次试讲中这两道题被作为课末练习提出；实际教学可先安排更简单的代数函数证明，再逐步提高难度。*
